# 農信保保證手續費一次總繳試算器資料說明

## 資料來源

資料來源為「附錄十八、農業信用保證手續費一次總繳簡捷查索表」，包含表甲、表乙、表丙。

表列金額皆為「保證金額每萬元之保證手續費」，並以年率 0.1% 為計算基礎。第一版資料層只整理表列值，不重新折現、不自行推導公式取代表格。

## 表甲、表乙、表丙用途

表甲 `fee-table-a.json` 用於一般貸款型態：

- 貸款到期償還。
- 本金分期平均攤還，每月、每三個月、每六個月或每年攤還一次。

表乙 `fee-table-b.json` 用於本金有寬緩期後再分期平均攤還：

- `grace_1`：本金寬緩 1 年，第二年起分期平均攤還。
- `grace_2`：本金寬緩 2 年，第三年起分期平均攤還。
- `grace_3`：本金寬緩 3 年，第四年起分期平均攤還。

表丙 `fee-table-c.json` 用於本息按月平均攤還款（年金法）。第一層 key 為貸款年利率，不是保證手續費率；第二層 key 為貸款期限年數。

## JSON 檔案說明

- `fee-table-meta.json`：共用資料來源、單位、基本費率、四捨五入規則、費率倍數與支援的還款型態。
- `fee-table-a.json`：表甲查表資料。
- `fee-table-b.json`：表乙查表資料。
- `fee-table-c.json`：表丙查表資料。
- `validation-cases.json`：後續查表與試算邏輯的基本驗證案例。

## 費率倍數說明

表列金額以年率 0.1% 為基礎。後續試算時，應依實際保證手續費率套用 `fee-table-meta.json` 的倍數：

- 0.1%：乘以 1。
- 0.15%：乘以 1.5。
- 0.35%：乘以 3.5。
- 0.5%：乘以 5。
- 0.7%：乘以 7。
- 1.0%：乘以 10。

## 四捨五入規則

保證手續費計算至元為止，元以下四捨五入。

一次總繳保證手續費已按年率 5% 優待；資料層已採用表列結果，不再另外折現。

## 第一版不支援範圍

第一版只建立資料層，不包含：

- 試算器頁面或 UI。
- 首頁入口或導覽連結。
- 表格不存在年限、利率或條件的插補。
- 以公式推導取代表格查表。
- 使用者輸入檢核、錯誤提示或完整試算流程。
- PDF 講義、下載功能或列印格式。

## 後續試算器計算公式

後續試算器應先依還款型態、年限、寬緩年數、攤還頻率或貸款年利率查出表列每萬元手續費，再套用實際保證金額與費率倍數：

```text
一次總繳保證手續費 =
表列每萬元手續費 ×（保證金額 / 10,000）× 費率倍數
```

最後元以下四捨五入。
