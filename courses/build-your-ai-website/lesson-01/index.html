Plan clearly

ChatGPT：幫你把想法整理清楚

ChatGPT 適合協助討論、說明、規劃、比較與整理需求。

在網站建置流程中，可以把它理解成企劃師與顧問。

它可以協助你：

  • 釐清網站目的
  • 找出主要訪客
  • 規劃網站分類
  • 安排首頁內容順序
  • 撰寫標題與介紹文字
  • 將模糊想法整理成可交付的施工需求
範例對話

我想建立一個官網，放 AI 課程、影片、Podcast 與作品，但不知道首頁應該怎麼安排。

AI 的建議仍需要由人確認目的、內容與最終決定。

Build carefully

Codex：進入專案實際完成工作

Codex 可以閱讀專案檔案、提出修改計畫、編輯程式碼、執行指令與檢查結果。

在網站建置流程中，可以把它理解成 AI 工程師。

它可以協助：

  • 閱讀 HTML、CSS、JavaScript 與 JSON
  • 新增或修改網站頁面
  • 檢查連結與版面
  • 執行測試與檢查
  • 顯示 git diff
  • 建立 commit
  • 在取得權限及正確設定後 push 到 GitHub
Codex 能做多少事情，取決於你授予的資料夾、repository、工具與權限。重要修改前應先確認工作範圍，完成後應檢查差異。

選擇 Codex 的使用方式

初學者建議

ChatGPT 桌面版中的 Codex

適合不熟悉終端機，希望從圖形介面開始的人。

  1. 前往 ChatGPT 下載頁。
  2. 下載 Windows 或 macOS 桌面版。
  3. 使用 ChatGPT 帳號登入。
  4. 建立工作、專案，或開啟資料夾。
  5. 依目前介面選擇 Chat、Work 或 Codex。
  6. 加入需要處理的資料夾與任務說明。
下載 ChatGPT查看官方桌面版說明
終端機使用者

Codex CLI

適合已經習慣使用終端機、需要在本機 repository 中直接工作的使用者。

macOS／Linux 官方安裝指令

curl -fsSL https://chatgpt.com/codex/install.sh | sh

安裝後執行

codex

第一次執行時，依畫面選擇使用 ChatGPT 帳號或其他可用方式登入。

查看 Codex CLI 官方說明
Windows 使用者若不熟悉終端機，建議先採用 ChatGPT 桌面版。需要 CLI 時，請依 Codex CLI 官方文件目前提供的 Windows 安裝方式操作，不要在頁面自行杜撰或寫死未經確認的 Windows 指令。

Safety first

先保護好你的帳號與專案

  • 不要把密碼或 access token 貼進公開網頁
  • 不要把 token 寫在 HTML、JavaScript 或 JSON
  • 不要把含 token 的網址傳給別人
  • 操作前先確認 Codex 目前所在的資料夾與 repository
  • 第一次任務先採只讀，不要直接要求修改或發布
  • 每次修改後都應查看 git diff 與變更檔案

First task

先閱讀，不修改

第一次任務不要急著請 Codex 做網站。先確認它看得到正確資料夾，也能清楚回報內容。

請先閱讀目前資料夾。

告訴我：

1. 目前有哪些檔案與資料夾。
2. 這個專案看起來是做什麼的。
3. 哪些檔案可能是首頁、樣式與主要程式。

不要修改任何內容。
不要建立檔案。
不要執行 commit 或 push。

Verify the result

如何判斷第一次任務成功

  • Codex 沒有修改任何檔案
  • 回報的資料夾是你預期的專案
  • 能指出可能的首頁與樣式檔
  • 沒有執行 commit 或 push
若 Codex 顯示的專案名稱或資料夾不對，先停止，不要繼續施工。
