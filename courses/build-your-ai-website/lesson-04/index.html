建立 GitHub Repository

為你的網站建立正確的專案空間與版本起點。

主題
建立網站專案
建議時間
約 20～35 分鐘
實作成果
建立自己的網站 repository
本課目標核心觀念實際操作可複製指令常見錯誤完成檢查

本課你會完成什麼

確認 GitHub username
選擇正確 owner 與名稱
建立 main branch
讓 Codex 只讀確認專案

建立前與命名規則

先確認已有 GitHub 帳號、知道 username，並決定 User site 或 Project site。本指南主線採 User site。

若 username 是 example-user，repository 必須是 example-user.github.io。大小寫、連字號與拼字都要確認。

建立步驟

  1. 登入 GitHub 並建立新 repository。
  2. 選擇正確 owner。
  3. 輸入正確名稱。
  4. 本課範例採 Public。
  5. 可建立 README，讓 main branch 立即存在。
  6. 完成建立並確認 branch 為 main。

GitHub 介面可能更新，請以官方目前畫面為準。

Public repository 安全提醒

公開 repository 不得放入密碼、token、身分證件、私人文件、未公開資料或內部機密。

讓 Codex 進入正確 repository

可使用 ChatGPT／Codex 當前提供的 GitHub 連線方式，或先在本機 clone repository，再讓 Codex 開啟該資料夾。不要把 token 貼進 Prompt；介面可能更新，請依官方目前說明操作。

第一次只讀確認

請先確認目前 repository。

請回報：
1. repository 名稱
2. 目前 branch
3. 遠端 origin
4. 現有檔案
5. 工作樹是否乾淨

不要修改任何檔案。
不要建立 commit。
不要 push。

正確結果範例

repository: example-user/example-user.github.io
branch: main
工作樹: clean

官方資源

查看 GitHub 官方建立 repository 文件

常見錯誤

  • 建錯 owner
  • repository 名稱少了 .github.io
  • 在錯誤 repository 施工
  • 將 token 貼進 Prompt
  • main 與其他 branch 混淆
  • 工作樹不乾淨仍繼續操作
