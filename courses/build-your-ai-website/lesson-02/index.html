三個核心觀念

GitHub：保存專案與版本

GitHub 是保存專案檔案、記錄版本並支援協作的平台。它能看見檔案與 commit，但 GitHub 頁面本身不等於訪客瀏覽的正式網站。

Repository：專案資料夾＋版本歷史

一個 repository 通常包含 index.html、styles.css、app.js、assets/ 與 README.md，並保留每次 commit 的修改紀錄。

GitHub Pages：把檔案發布成網站

  1. 網站檔案
  2. GitHub Repository
  3. GitHub Pages
  4. 公開網站網址

四種容易混淆的網址

先替換成自己的資料

本指南使用 <username> 代表你自己的 GitHub 使用者名稱。實際操作時，請將 <username> 替換成自己的帳號名稱，不要輸入左右兩側的 < >。<repository-name> 則代表你自行建立的 repository 名稱。

假設 GitHub 使用者名稱是 example-user，那麼 <username>.github.io 實際應輸入為 example-user.github.io。example-user 只用來示範替換方法，不要把它當成固定帳號名稱。

類型範例／用途能否分享
公開網站https://<username>.github.io/
給一般訪客瀏覽		可以
Repositoryhttps://github.com/<username>/<username>.github.io
查看檔案與 commit		公開 repository 可以
Git clonehttps://github.com/<username>/<username>.github.io.git
複製專案到本機		網址可以，但不能含憑證
Token／驗證資訊授權工具操作帳號絕對不可以
不要將 token 直接放進網址、HTML、JavaScript、JSON、截圖或公開對話。

User site 與 Project site

User site

Repository 名稱是 <username>.github.io，完整 repository 是 <username>/<username>.github.io，公開網址是 https://<username>.github.io/。

Project site

一般 repository 是 <username>/<repository-name>，網址通常是 https://<username>.github.io/<repository-name>/。

這個網站採用的架構

Chao AI 實作所採用 GitHub Pages 的 User site 架構。它的 repository 命名與公開網址符合通用規則：Repository 為 <username>/<username>.github.io，公開網站為 https://<username>.github.io/。實際帳號名稱不是學員操作時應照抄的內容。

請 ChatGPT 幫我辨認網址

請用初學者能理解的方式，幫我判斷以下網址分別是：

1. 公開網站網址
2. GitHub repository 網址
3. Git clone 網址
4. 可能含有敏感驗證資訊的網址

請說明每一種網址的用途、能否公開分享，以及安全注意事項。

不要要求我提供密碼或 token。

常見錯誤

  • 把 repository 網址當成正式官網
  • 把 token 寫在網址裡
  • repository 名稱拼錯
  • 誤以為 push 後一定立即更新
  • 分不清 User site 與 Project site
