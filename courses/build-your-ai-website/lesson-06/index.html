發布前檢查

首頁與樣式存在
連結與手機正常
沒有 token
diff 只有預期檔案

Git 四個動作

  1. 修改
  2. stage
  3. commit
  4. push
git status
git diff
git add index.html styles.css
git commit -m "Create first website"
git push origin main

先理解結果，不要盲目執行。

使用 Codex 發布

請準備發布目前網站。先確認 repository、main、git status 與 git diff；檢查連結、390px、console error 與敏感資訊。全部通過後 commit，message：Create first website，push 到 main，回報 commit hash 與遠端 main。

啟用 GitHub Pages

  1. Repository
  2. Settings
  3. Pages
  4. main／root

介面可能更新，以官方目前畫面為準。User site 是 https://<username>.github.io/；Project site 再加 repository 名稱。

發布後驗證

  • 開啟正式網址與強制重新整理
  • 手機瀏覽並點擊連結
  • 檢查圖片與 Console
  • 等待部署完成

常見問題

  • 404 或首頁不在來源
  • 快取造成未更新
  • CSS／圖片路徑錯誤
  • branch 或來源選錯
