Codex 的三階段工作法

  1. 先閱讀
  2. 先提出計畫
  3. 確認範圍後才修改

index.html 負責內容與結構；styles.css 負責顏色、排版與響應式設計。

第一版網站範圍

只建立 index.html 與 styles.css，包含名稱、介紹、內容區、外部連結與頁尾。不加入登入、資料庫、後端、複雜動畫或會員系統。

高品質指令七部分

  • 正確 repository
  • 任務目標
  • 允許修改檔案
  • 禁止修改內容
  • 視覺需求
  • 驗證方式
  • 是否 commit／push

可複製 Codex 建站指令

請在目前 repository 建立第一版個人官網。開始前確認 repository、main branch、乾淨工作樹；先閱讀並回報計畫。只允許修改 index.html、styles.css。網站名稱：【填寫】；介紹：【填寫】；主要內容：【填寫】；外部連結：【填寫】。要求繁體中文、手機與桌機可讀、不用外部框架或套件、鍵盤可操作、390px 無溢出。不要修改其他檔案、建立登入或後端、寫入密碼或 token、commit 或 push。完成後回報修改檔案、結構、手機檢查、git diff、console error。

預覽與 Chao AI 案例

檢查桌機、390px、連結、Console 與 git diff。Chao AI 實作所也是先有首頁，再逐步加入課程、影片、Podcast 與作品。

常見錯誤

  • 修改整個 repository
  • 沒有限制檔案或檢查工作樹
  • 未確認就 commit
  • 第一版功能太多
  • 只看畫面不看 diff
